## 三个页签

```
┌─ 看板 ────────────────────────────────────┐
│  状态卡：现在靠什么在干活                     │
│    ✓ 框架已接管 N 个应用                     │
│    ✓ 订阅 id667 v618（多久前更新）            │
│    ⚠ 有问题时这里直接说怎么修，不让用户猜       │
│  今天拦了：藏掉 x · 点掉 y · 断网 z           │
│  [抓一条规则]  [同步订阅]                     │
├─ 应用 ────────────────────────────────────┤
│  按命中数排序，每行显示「这个应用拦了多少」      │

│    · 一句人话 + 最近有没有命中 + 开关          │
│    · 底部：「还有广告？」→ 直接进抓取          │
├─ 设置 ────────────────────────────────────┤
│  下面这四组                                  │
└───────────────────────────────────────────┘
```

「统计」页签取消（内容就是看板上那一行）。

## 设置页四组

**▎ 拦什么**
- 页面上的广告 ▸ 藏掉 / 藏不住就摘掉 / 整页不让打开
- 替我点掉 ▸ 跳过按钮 · 弹框 · 更新提示 · 青少年模式提示
- 广告的网络连接 ▸ 域名表三选一
- 应用里的广告 SDK ▸ 不让它启动 · 去掉摇一摇 · 去掉截图限制

**▎ 规则从哪来**
- 订阅 ▸ 内置 / 自己填地址 / 检查更新频率
- 我自己抓的 ▸ 列表 + 导出
- 内置通用规则 ▸ 跳过词表 · 广告 SDK 前缀表

**▎ 省电**
- 省电档位 ▸ 激进 / 均衡 / 保守（一个旋钮管多个参数）
- 无障碍 ▸ 状态 +「有框架时自动待机」说明（不是开关）

**▎ 出问题了**
- 自检 ▸ 拿真规则跑一遍判定
- 最近拦了什么 ▸ 命中记录
- 详细日志 ▸ 开关（默认关）
- 备份与恢复
- 高级 ▸ APK 分析 · 批量扫描（高危的收在这里）

## 命名要说人话（4.5 对照表）

| 机制名 | 界面上写 |
|---|---|
| 页面净化 | 藏掉页面上的广告 |
| 自动跳过 | 替我点掉 |
| 域名拦截 | 不让广告联网 |
| 暂停全部净化 | 全部暂停 |

## 底栏（抓屏时）

手指滑过哪个就高亮哪个，抬手选中（长按选父容器）→
**底栏给一句建议 + 理由**（如「建议：点击 —— 文案里写着『跳过』」）→ 按一下就进草稿。
广告常跨页（开屏 → 信息流 → 插屏），切页继续点，草稿累积。

## 交互上我这边的重新设计（旧版没有 / 我改的）
