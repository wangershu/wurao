无扰 UI 对齐「大圣净化」设计稿

基准：AdHammerX 源码（github.com/wangershu/wurao，miuix 0.9.4 + HyperIsland 版式）· 截图全部真机直采（小米 2509FPN0BC / Android 16）

一句话：信息架构和业务逻辑一行不动，把视觉层整体换成大圣净化那套 —— 可折叠大标题、分组卡片、状态网格、悬浮胶囊底栏，组件层从参考实现直搬（包名同为 com.wurao.ui，零翻译成本）。

1 · 对齐目标：大圣净化四屏（真机截图）

原版主页：状态网格 + 警告横幅 + 信息卡
原版应用：大标题 + 搜索 + 分组行
原版设置：分组卡片 + 图标行
原版关于：渐变沉浸页

2 · 无扰现状 vs 目标（逐页对照）

2.1 主页

现状无扰 0.1.0
→对齐
目标大圣净化 1.2.2
  • 状态网格（左大卡 + 右两小卡）和配色已对齐，保留
  • 标题是小号居中小标题 → 改为 可折叠大标题（title + largeTitle，滚动收成小标题）
  • 信息卡是自定义 InfoRow → 改为 RowGroup + KeyValue 行（18×14 内边距）
  • 底栏三图标全灰、看不出选中 → 选中项自绘胶囊高亮（primary 14% 底 + primary 图标）
  • 「常用」区按钮堆砌（全部暂停 / 抓规则 / 同步 / 检测链接）→ 收成一张 RowGroup，暂停改 SwitchRow（状态可见）
  • 命中记录列表散在主页滚动层里 → 保留，但每条改标准卡片行，按钮换 TextButton 风格

2.2 应用页

现状无扰 0.1.0
→对齐
目标大圣净化 1.2.2
  • 搜索框是 material 描边样式 → miuix 圆角填充搜索框
  • 列表项是直角小圆角 → 整卡 16dp 圆角，行内边距统一 18×14
  • 「应用 / 共 283 个应用」双标题冗余 → 大标题副标题直接显示数量（原版：应用 / N 个应用）
  • 「只看拦过的」开关错位 → 改为标准 SwitchRow
  • 行尾箭头是 material ChevronRight → MiuixIcons.ArrowRight 10×16
  • App 图标 + 名称 + 包名/命中次数的行结构保留

2.3 设置页

现状无扰 0.1.0
→对齐
目标大圣净化 1.2.2
  • 「展开行里塞表单」→ 改为分组卡片 + 二级页（导入订阅 / 我的规则 / 备份恢复各自独立成页）
  • material 蓝色 Switch 与图标 → 全部换 miuix 组件 + MiuixIcons（tint 跟正文走）
  • 分组随意（外观+关于挤一张卡）→ 按原版分组：规则 / 数据 / 外观 / 其他，每组一张卡
  • 纯文字说明段落裸放在页面上 → 收进卡片或改为 Kit.Note 说明样式

3 · 设计规范（数值已定，照抄参考实现）

项规格
主题MiuixTheme(controller = ThemeController(...))，禁止 colors= 写法（绕过 typography，数字会渲染成豆腐块）；edge-to-edge 透明系统栏
页面骨架Kit.Page：TopAppBar 同给 title + largeTitle，MiuixScrollBehavior 折叠；LazyColumn 左右 12dp、item 间距 12dp、overScrollVertical
行规格内边距 18×14dp；行尾箭头 10×16；分组标题 SmallTitle 18×8；一卡多行 = Card(insideMargin=0) 套 Column
状态卡激活 #36D167 / 底 #DFFAE4 · 未激活 #FF5A52 / 底 #FFE5E3 · 警告底 #FFF3D6 / 字 #704D00
水印自绘描边圆 + 勾，右下角 offset(12,16)，外层必须 clip 圆角 16（否则溢出压到相邻卡）
底栏只根页显示；悬浮胶囊不 fillMaxWidth；选中高亮自绘：primary.copy(alpha=.14) 圆角 50 胶囊底 + primary 图标色
二级页Kit.DetailPage：同骨架 + 左上返回（MiuixIcons.Back）；整层覆盖根页，底色用 colorScheme.surface（不是 background，那是卡片白）

4 · 工程方案

文件拆分（1970 行单文件 → 五个）

ui/Kit.kt
组件层（从参考直搬） ui/Nav.kt
三页签 + 返回栈 ui/Home.kt ui/Apps.kt ui/Settings.kt ← MainActivity.kt
只留入口/调试直达/业务胶水

导航

  • 引入参考实现的 Navigator（返回栈 + switch/jump），替换 tabState / openPkg / subPage 三个散装 state
  • 根页切换用 HorizontalPager（页面状态不丢）；二级页整层滑入覆盖
  • 调试直达全部保留：--es tab / --es open_pkg 翻译成 Navigator 调用（真机验证唯一手段，设备无 INJECT_EVENTS）

依赖

  • miuix 0.9.0 aar → libs 里已有的 0.9.4 aar（ui / icons / preference；core/shapes 沿用 0.9.0）。两项目构建链已核实一致：AGP 9.4.1 / Kotlin 2.4.21 / Gradle 9.8.1，当年「0.9.4 编不过」的注释已过时
  • 退路：0.9.4 仍编不过就回 0.9.0（已 javap 核实其 TopAppBar 带 largeTitle），Kit 个别参数按 0.9.0 签名微调

5 · 不做

  • 不动信息架构（三页签）、不动任何业务逻辑与 hook 侧代码
  • 不做深色模式单独调优（miuix 跟随系统自带）
  • 不引入 navigation-compose（返回栈够用）
  • 不抄参考实现里本项目没有的功能页（统计独立页、AI 助手、批量扫描等）
